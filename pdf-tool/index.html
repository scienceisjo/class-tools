PDF를 나누기

페이지를 미리 보면서 드래그로 범위를 선택하거나, 페이지 사이 가위(✂)로 잘라 나눕니다.

클릭하거나 파일을 여기로 끌어다 놓으세요 PDF 파일 1개
· 페이지를 클릭(터치는 톡 누르기)하면 선택돼요. 마우스로 드래그하면 여러 쪽이 한꺼번에 선택돼요(파란색). 휴대폰·태블릿은 길게 누른 채 끌면 여러 쪽이 골라져요. · 페이지 사이 ✂를 누르면 그 자리에서 잘려요(색깔 구간으로 나뉨).

‘번호로 선택’·‘몇 쪽씩’은 화면에 표시만 해요. 실제 저장은 아래 파란/초록 버튼을 누르세요. ‘용량으로 나누기’는 바로 저장돼요(이메일 첨부 용량 제한용).

PDF 용량 줄이기

이미지가 많거나 스캔한 PDF의 용량을 크게 줄입니다. 흑백 변환으로 잉크도 아껴요.

클릭하거나 파일을 여기로 끌어다 놓으세요 PDF 파일 1개
※ 모든 쪽을 사진으로 다시 찍어 담는 방식이라 스캔본·사진 PDF에서 효과가 큽니다.
이 PDF는 글자가 살아 있는 문서예요. 압축하면 모든 쪽이 사진으로 바뀌어 글자 선택·검색·복사가 안 되고, 용량도 거의 안 줄거나 오히려 커질 수 있어요. 원본 한글·워드 파일이 있다면 거기서 PDF로 다시 저장하는 편이 더 작고 선명해요.

페이지 정리 (회전 · 삭제 · 순서 바꾸기)

페이지를 미리 보면서 회전하고, 지우고, 순서를 바꾼 뒤 새 PDF로 저장합니다.

클릭하거나 파일을 여기로 끌어다 놓으세요 PDF 파일 1개
각 페이지에서 ◀ ▶ 순서 이동 · ↻ 90°씩 회전 · ✕ 삭제(다시 누르면 복구)

쪽번호 매기기

모든 페이지에 자동으로 쪽번호를 찍어줍니다. 학습지 묶음·자료집 만들 때 좋아요.

표지만 빼려면 2, 표지와 목차 두 쪽을 빼려면 3을 넣으세요. 그 쪽이 '시작 번호'를 받아요.

클릭하거나 파일을 여기로 끌어다 놓으세요 PDF 파일 1개 (스캔 이미지 PDF는 글자 추출이 안 될 수 있어요)

OCR — 스캔본 글자 인식

스캔한 PDF나 사진 속 글자를 인식해서 텍스트로 만들어 줍니다. 한국어·영어를 알아보고, 인식도 이 컴퓨터 안에서 이루어져요.

클릭하거나 파일을 여기로 끌어다 놓으세요 PDF 1개 또는 사진 여러 장 (JPG, PNG)
※ 처음 실행할 땐 인식 자료(한국어 약 7MB, 영어 약 11MB)를 받아 오느라 시간이 걸려요. 한 번 받아 두면 그다음부터는 인터넷이 끊겨도 됩니다. 이후 페이지당 수 초~수십 초 걸리고, 글자가 선명할수록 정확합니다.
