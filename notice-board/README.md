# 📺 전자칠판 공지 시스템 — 설치 & 운영 가이드

해누리중학교 전자칠판에 상시 띄워둘 공지 페이지입니다.
기존 **질문나무**와 같은 Supabase 프로젝트·배포 방식을 그대로 사용합니다.

## 구성 파일

| 파일 | 용도 |
|---|---|
| `notice_migration.sql` | DB 테이블 생성 (1회 실행) |
| `notice_display.html` | 🖥️ 전자칠판에 띄우는 화면 (읽기 전용) |
| `notice_admin.html` | 🧑‍🏫 교사용 공지 입력 대시보드 |
| `notice_sample_data.sql` | (선택) 미리보기용 예시 데이터 |

---

## 1단계 — DB 준비 (최초 1회)

1. Supabase 대시보드 → **SQL Editor** 열기
2. `notice_migration.sql` 내용 전체 붙여넣고 **Run**
3. 맨 아래 결과에 `공지수 / 일정수 / 시간표변경수 / 디데이수 / 평가일정수 / 호출수 / 청소당번수 / 분실물수 / 설정수`가 나오면 성공

> 기능이 계속 추가되었으니(디데이·평가일정·학생호출 등) `notice_migration.sql`을 **다시 실행**하세요 (안전하게 재실행됩니다).

4. *(선택)* 화면을 바로 채워보고 싶으면 `notice_sample_data.sql`도 실행 → 예시 공지·일정·디데이가 들어갑니다. 지울 때는 파일 맨 아래 "샘플 삭제" 블록 사용.

> 여러 번 실행해도 안전합니다 (`IF NOT EXISTS` 기반).

## 2단계 — 배포

기존 배포 방식과 동일합니다.

```bash
node deploy.js            # 전부 배포 (학생앱 + 교사 + 공지)
node deploy.js --notice   # 전자칠판 공지만 배포
git push origin main
```

또는 Windows에서 `deploy.bat` 더블클릭 → `4` (전자칠판 공지만)

배포 후 URL:
- 🖥️ 전자칠판: `https://[username].github.io/question-orchard/notice.html`
- 🧑‍🏫 공지 관리: `https://[username].github.io/question-orchard/notice-admin.html`

## 3단계 — 교사 사용법

1. `notice-admin.html` 접속. **질문나무와 별개인 공지 전용 계정**을 씁니다.
   - **처음이면 [가입]** 탭에서 이름·이메일·비밀번호·**가입 코드**로 계정을 만드세요. (가입 코드는 ⚙️ 설정에서 정함, 기본 `haenuri2026` — 꼭 바꾸세요)
   - 가입할 때 **담당 과목**을 적어두면 교과 공지 작성 시 자동으로 채워집니다.
   - **👀 둘러보기** 버튼을 누르면 로그인 없이 **읽기 전용**으로 안에 어떤 내용이 있는지 둘러볼 수 있습니다(작성·수정 불가).
   - ※ 질문나무 교사 계정으로는 로그인되지 않습니다(별개 시스템).
2. 탭에서 작성:
   - **📢 공지사항** — 일반 / 🚨 긴급 / 📚 교과별 / 🎓 학년. *긴급*은 화면 상단에 빨간 띠로 흐릅니다. *노출 종료일*을 정하면 그날 이후 자동으로 사라집니다.
   - **📅 주요일정** — 시험·행사 등. 다가오는 일정만 화면에 표시됩니다.
   - **🔄 시간표 변경** — 해당 **날짜 당일에만** 전자칠판에 표시됩니다.
   - **🎯 디데이** — 기말고사·수행평가·방학 등 목표일까지 남은 일수(**D-15**)를 화면 상단 띠에 표시. 유형(시험🟥/평가🟨/방학🟩/기타)별로 색이 다르고, 당일은 **D-DAY**로 강조됩니다. 지난 날짜는 자동으로 사라집니다.
   - **📋 평가일정** — 과목·유형(수행/지필)·평가일·시험범위를 등록하면 화면 좌측 *다가오는 평가* 칸에 날짜순으로 표시됩니다. 지난 평가는 자동으로 사라집니다.
   - **📣 학생 호출** — 학년·반을 고르면 **학생 명단(DB)**이 자동으로 불러와집니다. 학생을 선택하고 *오라는 곳*(기본 교무실)을 적어 **호출하기**를 누르면, 전자칠판 상단 **📣 호출 띠**에 즉시 표시됩니다. 학생은 직접 찾아가지 않아도 화면에서 확인합니다. 학생이 오면 **✅ 완료**를 눌러 호출을 해제하세요. (명단에 없는 학생은 이름을 직접 입력)
   - **🧹 청소당번** — 학년·반·구역·담당을 입력하면 그 반의 **교실 보드**(`?class=학년-반`) 하단에 표시됩니다. 매주 갱신.
   - **🙋 1인1역** — 반별 역할 배정(우유당번·전기·알림장 등). 자주 쓰는 역할 10개는 버튼 한 번으로 입력됩니다. 교실 보드의 청소당번 칸에서 **🙋 1인1역 버튼을 누르면 전환**되어 보입니다(전자칠판 터치).
   - **🔍 분실물** — 물건·발견장소·보관장소·(선택)사진을 등록하면 전교 보드 공지에 함께 순환 표시됩니다. 주인이 찾아가면 **✅ 찾아감** 처리.
   - **⚙️ 설정** — 학교명, 공지 카드 전환 속도(초), NEIS 코드, 교실별 보드 주소 생성.

   > 🔗 **QR 공지**: 공지 작성 시 **링크 URL**을 넣으면 화면 공지 카드에 **QR코드**가 함께 떠서, 학생이 휴대폰으로 신청서·설문을 바로 열 수 있습니다.

> **📚 과목별(교과) 공지**는 공지 작성 시 카테고리를 **교과별**로 고르면 — **로그인한 선생님의 담당 과목·학년이 자동으로 채워집니다.** 화면에는 `📚 수학 · 2학년`처럼 과목이 함께 표시됩니다.

### 🖥️ 전자칠판에서 호출 확인 (드롭다운 필터)
화면 상단 **📣 호출** 띠의 드롭다운에서 **반을 선택**하면 그 반의 호출만 골라 볼 수 있습니다(전자칠판 터치로 조작). 호출이 있으면 띠가 주황색으로 강조됩니다. 호출은 **최근 4시간 이내 활성 건**만 표시되고, 선생님이 *완료* 처리하면 사라집니다.

> 공지를 올리면 **전자칠판에 즉시 반영**됩니다(실시간). 새로고침 불필요.

## 4단계 — 전자칠판에 상시 표시

전자칠판/TV의 웹브라우저에서 `notice.html` 주소를 열고 **전체화면(F11)**.

**자동 시작(키오스크) 설정 (권장):**
- Chrome 바로가기 만들고 대상에 추가:
  ```
  chrome.exe --kiosk --app=https://[username].github.io/question-orchard/notice.html
  ```
- Windows 시작프로그램에 이 바로가기를 넣으면 부팅 시 자동 표시됩니다.

> 💡 **미리보기(데모) 모드**: 주소 뒤에 `?demo=1`을 붙이면(`notice.html?demo=1`) DB 없이 **샘플 데이터로 화면 구성을 미리** 볼 수 있습니다. 실제 운영 시에는 붙이지 마세요.

### 중앙 보드 vs 교실별 보드
- **중앙(복도·현관 전교용)**: 그냥 `notice.html` — 전교 정보를 모두 표시
- **교실별**: `notice.html?class=2-3` 처럼 붙이면 그 교실 보드가 됩니다.
  - 헤더에 **`2학년 3반`** 배지 표시
  - **시간표 변경**은 그 반(+전체) 것만, **호출**은 그 반으로 기본 필터
  - 주소는 관리자 **⚙️ 설정 → 🖥️ 전자칠판 주소**에서 학년·반만 고르면 자동 생성됩니다.

**자동 동작:**
- 시계: 실시간 · **현재 교시/쉬는시간**(🔔 3교시 ~11:40) 자동 표시(평일 등교시간만)
- 급식·날씨: 자동 갱신
- 공지 여러 개면 카드가 자동으로 순환(기본 12초)
- 인터넷이 끊겨도 마지막 정보를 유지하며 우하단에 "연결 끊김" 표시
- 화면 번인 방지를 위해 화면이 미세하게 이동

> ⏰ 교시 시간은 학교마다 다릅니다. 현재는 일반적인 시간표가 기본값이며, 바꾸려면 알려주세요(`notice_display.html`의 `BELL` 부분).

## 🔒 개인정보 보호 — 꼭 지켜주세요

전자칠판은 **복도/교실에서 누구나 보는 공개 화면**입니다. 다음은 **절대 올리면 안 됩니다.**

| 금지 | 이유 |
|---|---|
| 성적·석차·점수 | 개인정보·서열 노출 |
| 징계·선도·벌점 | 명예훼손·낙인 |
| 상담/Wee·건강·보건실·진료 내용 | 민감정보 |
| 가정형편·급식비/교육급여 등 지원 대상 | 민감정보 |
| 개인 연락처·주소·주민번호 | 개인정보 |
| 동의 없는 학생 사진 | 초상권 |

시스템에도 안전장치가 있습니다:
- **학생 호출**: 화면에는 **이름·반·장소만** 표시되고 **사유는 절대 표시되지 않습니다**(사유는 관리자에서만 확인용).
- **공지 작성 화면**에 위 금지 항목 안내가 항상 떠 있습니다.

## 자동 연동 (별도 설정 불필요 — 교사 입력 0)

- **급식** — NEIS 급식 API 자동 수신 + **알레르기 번호** 작게 표시. 주말·휴일이면 다음 급식일.
  - 해누리중학교: 교육청 `B10`(서울) · 학교코드 `7130256`
- **📖 오늘 시간표 (교실 보드)** — `?class=학년-반` 보드는 NEIS에서 그 반의 **오늘 교시별 시간표를 자동 표시**. 시간표 변경(빨강 취소선→새 과목)과 📍장소가 그 위에 겹쳐 보입니다.
- **🏫 학사일정** — NEIS 학사일정(방학·고사·공휴일 등)이 주요일정에 자동 병합. 같은 이름 연속 일정은 기간(7/20~8/16)으로 묶임.
- **😷 미세먼지** — 좋음🟢/보통🔵/나쁨🟠/매우나쁨🔴 헤더 배지 (한국 기준, 30분마다).
- **☔ 우산** — 오늘 강수확률 40% 이상이면 헤더에 `☔ 60%` 배지.
- **날씨** — 현재 기온·날씨 아이콘.

### 📍 수업 장소 안내 (교사 입력)
관리자 **🔄 시간표 변경 탭** 안에 있습니다. "오늘 체육 어디서 해요?"에 답하는 기능 —
날짜·학년·반·교시·과목을 고르고 장소 버튼(운동장/체육관/강당/시청각실/도서관/과학실/음악실/미술실)을 누르면
전자칠판에 `체육 📍체육관 (미세먼지)` 처럼 표시됩니다. 해당 날짜에만 보이고 다음 날 자동으로 사라집니다.

> 다른 학교에서 쓰려면 **⚙️ 설정** 탭에서 NEIS 코드만 바꾸면 됩니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 화면에 "연결 끊김" | 인터넷 확인 / 1단계 마이그레이션 실행 여부 확인 |
| 공지가 안 보임 | 노출 종료일이 지났는지, 대상 학년이 맞는지 확인 |
| 급식이 안 나옴 | 주말·시험·방학 등 급식 없는 날일 수 있음 (정상) |
| 로그인 실패 / "권한 없는 계정" | 공지 전용 계정이 아닙니다. [가입] 탭에서 새로 가입하세요(질문나무 계정과 별개) |
| 가입이 안 됨 | 가입 코드가 맞는지 확인(⚙️ 설정의 코드). 이미 쓰는 이메일이면 다른 이메일로 |
