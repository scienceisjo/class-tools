자비스 사용 안내

손뼉 두 번에 깨어나는 수업 도입 도우미 — 아이언맨의 인공지능 비서를 우리 교실로

scienceisjo.github.io/class-tools/jarvis/ 크롬 또는 엣지에서 여세요 · 마이크가 달린 컴퓨터(노트북·전자칠판)면 됩니다 · 설치 없음 · 무료

3분 요약

  1. 위 주소를 열고 SYSTEM INITIALIZE를 누릅니다. 마이크 권한을 물으면 허용.
  2. Ctrl+Alt+J 로 교사 콘솔을 열어 이름을 넣고, 음악 탭에서 곡 파일을 고르고(여러 개 한꺼번에 됩니다), 학습목표를 적은 뒤 Esc.
  3. F 로 전체화면. 아이들이 들어오면 아무 말 없이 손뼉을 두 번 치세요.

2번은 처음 한 번만 하면 됩니다(이 브라우저가 기억합니다). 학습목표만 수업마다 바꿔 주세요.

이게 뭔가요

수업 시작 3~5분을 위한 도구입니다. 손뼉을 두 번 치면 화면이 켜지며 "Welcome home, sir." 하고 인사하고, 말로 부르면 날씨·시간·음악·타이머를 띄워 줍니다. 마지막에 "오늘 학습목표"라고 하면 그날의 목표가 매번 다른 연출로 공개됩니다. 목표와 브리핑은 자비스가 한국어 음성으로 읽어 주고, 빈칸은 "빈칸"이라고 읽습니다. 목소리는 교사 콘솔 음성·마이크 탭에서 고를 수 있는데, 가장 자비스 같은 건 엣지로 열었을 때 나오는 Microsoft Ryan Online (Natural) – UK입니다. 영어 음성으로 말하고 한글 자막이 함께 뜹니다.

💡
핵심은 "안 망하는 구조"입니다. 교실이 시끄러워 말을 못 알아들어도 숫자키를 누르면 똑같이 움직입니다. 아이들은 눈치채지 못합니다. 아래 표의 "안 되면" 열을 봐 두세요.

교사 콘솔 (Ctrl + Alt + J)

학생에게 보이지 않는 설정 화면입니다. 고치는 즉시 저장되고, Esc로 닫습니다. 콘솔이 열려 있는 동안엔 숫자키가 먹지 않습니다.

막힐 때

마이크 권한 창이 안 떠요 / 박수를 못 알아채요

주소창 왼쪽 자물쇠(🔒) → 마이크 → 허용. 크롬·엣지가 아니면 음성 인식이 안 됩니다. 그래도 안 되면 Space로 부팅하고 숫자키로 진행하세요 — 아이들은 모릅니다.

파일을 더블클릭해서 열었더니 마이크가 안 돼요

브라우저가 file://에서는 마이크를 막습니다. 위의 웹 주소로 여세요.

말을 잘 못 알아들어요

교실 소음이 크면 그렇습니다. 음악이 나오는 동안엔 특히 안 되니 "음악 꺼" 다음에 다음 명령을 하세요. 영어로 말할 때는 "자비스"만 비슷하게 들려도 반응합니다. 급하면 숫자키.

박수에 반응이 없거나, 아무 소리에나 켜져요

콘솔 → 음성·마이크 → 박수 감도를 조절하세요. 동그라미 두 개가 박수에 켜지는지 보면서 맞추면 됩니다. 시끄러운 교실은 낮게(1~3).

목소리가 너무 작아요 / 안 나요

↑를 몇 번 누르세요(처음엔 중간 50%로 시작합니다). 그래도 안 나면 컴퓨터 자체 볼륨을 확인하세요. 영어 목소리가 아예 없으면 Windows 설정 → 시간 및 언어 → 음성에서 영어(영국) 음성을 추가하면 훨씬 자비스답습니다.

뽑기 결과를 제가 정할 수 있나요

네. "발표할 사람 뽑아줘" 하고 이름이 도는 3초 동안 숫자키를 누르면 그 모둠에서 뽑힙니다(모둠 뽑기면 그 모둠). 화면은 끝까지 무작위처럼 돕니다. 명단에 모둠 번호가 없으면 숫자는 그 번호의 학생입니다. "오늘 이미 뽑힌 사람 제외"를 켜 두면 하루 안에 같은 아이가 두 번 안 뽑힙니다.

아이들 명단이 어디로 가나요

어디로도 안 갑니다. 그 컴퓨터의 그 브라우저 안(localStorage)에만 있고, 서버가 없으며, 설정 파일로 내보낼 때도 명단은 자동으로 빠집니다. 컴퓨터를 바꾸면 다시 넣어야 합니다.

소음 신호등이 자꾸 빨강이에요 / 안 켜져요

콘솔 → 음성·마이크 → Noise Light 에서 예민함을 낮추세요(막대가 평소 수업 소리에서 초록이 되게). 마이크가 없으면 신호등은 뜨지 않습니다. 자비스가 말하거나 음악이 나오는 동안엔 재지 않으니 그때 빨강이 되진 않습니다.

급식이 "학교가 등록되지 않았습니다" 라고 해요

콘솔 → 기본 → School Meal 에서 학교 이름을 넣고 찾기 → 목록에서 우리 학교를 클릭하면 됩니다. 한 번만 하면 기억합니다. 주말·방학엔 "급식이 없습니다"가 정상입니다. 급식 API를 직접 가져와 내 앱을 만들고 싶으면 오늘 급식 페이지의 「이렇게 가져옵니다」를 보세요 — 우리 학교 코드가 채워진 주소와 프롬프트가 나옵니다.

노래를 여러 개 넣고 골라 틀 수 있나요

네. 콘솔 → 음악 탭에서 파일을 여러 개 한꺼번에 고르면 목록에 쌓입니다. 목록의 ▶ 를 누르면 그 곡으로 바뀌고, 수업 중에는 [ ] 로 곡을 넘깁니다. 말로 "다음 곡" 이라고 해도 됩니다. 곡이 끝나면 다음 곡으로 넘어갑니다(한 곡뿐이면 반복).

노래 앞부분을 건너뛰고 싶어요

← → 로 10초씩, Shift와 함께 누르면 30초씩 건너뜁니다. 화면 위에 곡 이름과 진행 막대가 잠깐 떠서 어디쯤인지 보입니다. 말로는 "앞으로 감아" · "처음부터".

음악이 안 나와요

콘솔 → 음악 탭에서 파일을 다시 고르세요. 고른 파일은 그 컴퓨터의 그 브라우저만 기억하므로, 다른 컴퓨터에서는 다시 골라야 합니다. 저작권 있는 곡은 공개 웹에 올리지 마세요.

설정이 사라졌어요

브라우저 데이터를 지우면 함께 지워집니다. 콘솔 → 저장·나눠주기에서 설정 내려받기로 파일을 받아 두면 언제든 불러올 수 있습니다.

동료 선생님께 나눠주기

링크만 보내면 됩니다. 내 대사·학습목표까지 그대로 주고 싶으면 콘솔 → 저장·나눠주기에서 설정 내려받기로 받은 jarvis-설정.json을 함께 보내세요. 받은 분은 같은 탭의 설정 불러오기로 넣으면 끝입니다. (음악 파일은 저작권 때문에 포함되지 않습니다.)
